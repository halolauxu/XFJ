## D. 81→95 分捡分清单

| # | 类别 | 提分 | 推荐原因 |
|---|---|---|---|
| 1 | **选择题原文匹配** | +4–6 分 | 70% 基础题，开卷可逐题翻书核对 |
| 2 | **道法材料题"是什么/为什么"**（套答题模板） | +3–4 分 | 模板覆盖率高 |
| 3 | **历史史料题"基础识别"**（时间/人物/事件） | +2–3 分 | 看到关键词→翻目录→定位章节 |

## E. 12-15 张保命卡（每张= 关键词→章节→答题套路）

### 道法

**卡1 · 国家安全** 八上 P90-105（红标）
- 模板：①树立总体国家安全观 ②增强国家安全意识 ③不浏览不传播涉密信息 ④发现可疑情况及时报告 ⑤履行维护国家安全的法律义务

**卡2 · 宪法** 八下 P2-25（蓝标）
- 模板：①宪法是国家根本法 ②具有最高法律效力 ③是其他法律的立法基础 ④规定国家根本制度和根本任务 ⑤公民应尊重和维护宪法

**卡3 · 全面依法治国** 九上 P40-55（蓝标）

**卡4 · 社会主义核心价值观（24 字）** 九上 P60-72（绿标）

**卡5 · 改革开放/创新驱动** 九上 P2-25（橙标）

**卡6 · 文化自信** 九上 P60-75（绿标）
- 模板：①坚定文化自信 ②传承中华优秀传统文化 ③弘扬革命文化 ④发展社会主义先进文化 ⑤推动文化交流互鉴

**卡7 · 民族团结/一国两制** 九上 P88-102（黄标）

## G. 8 个高频答题模板（直接背、考场直接套）

### 道法

**G1. "问国家安全的做法"** = 树立总体国家安全意识 + 学习国家安全知识 + 不浏览不传播涉密信息 + 发现可疑情况及时报告（拨打 12339） + 履行维护国家安全的法律义务

**G2. "问怎样践行社会主义核心价值观（青少年）"** = 努力学习 24 字内容 + 以富强民主文明和谐为目标（国家） + 追求自由平等公正法治（社会） + 做爱国敬业诚信友善的好公民（个人） + 把核心价值观融入日常学习生活

**G3. "问怎样实施全面依法治国"** = 科学立法（立法机关） + 严格执法（政府） + 公正司法（司法机关） + 全民守法（公民）

**G4. "问意义/为什么"通用** = 有利于…… + 推动了…… + 促进了…… + 增强了…… + 是……的需要 + 是实现……的必由之路（每个材料题从材料里抽 3-4 条对应展开）

**G5. "问做法"通用四层模板** = 国家：完善立法/制定政策/加强监管 + 社会：营造氛围/加强宣传 + 学校（家庭）：加强教育引导 + 个人（青少年）：增强意识+具体行动

### 历史

**G6. "问意义/影响"通用** = 政治影响（社会性质/政权/制度） + 经济影响（生产力/经济关系） + 思想文化影响 + 国际影响 + 深远影响（对今天的启示）

**G7. "问启示"通用** = 顺应历史发展潮流 + 符合本国国情/实事求是 + 坚持改革创新 + 重视发展生产力（科技/教育） + 维护国家利益（独立、统一）

**G8. "问评价历史人物/事件"通用** = 概括其主要活动（史实1-2句） + 性质（是什么） + 积极影响（推动……） + 局限性（受时代/阶级局限……） + 总评（在历史上占有重要地位）

## H. 教练对话引导

1. **学生说"这道题不会"** → "先念一遍题干。题里出现哪个 **3 字以上的固定词**？比如'国家安全''核心价值观''全面依法治国'？把它圈出来。"
2. **"我找不到在书里哪儿"** → "这个词是讲**国家**的、**社会**的还是**个人**的？讲**经济/政治/文化/法治**哪一块？先选大方向，再翻目录。"
3. **"翻到了但不知道抄哪几句"** → "找**红色字/黑体字**的 1-2 句话，再找**带'是''应'字**的判断句。这两类 80% 是得分句。"
4. **"不知道答几条够不够"** → "数你写了几个分号或编号？道法材料题至少要 **3-4 个角度**才能拿满分。再补 1-2 条。"
5. **"历史题完全不会做"** → "材料里有没有**年份**？有没有**地名**？有没有**人名**？把这三项圈出来，去课本目录找对应单元。"
6. **"不知道答多少字"** → "看分值。**4 分大概答 4 个要点；8 分大概答 6-8 个要点**。每个要点 1 句话就行。"
7. **"开卷怎么还会错"** → "翻书超过 **2 分钟**没找到就先跳过。开卷不是抄全书，是**抄关键词+稍作改写**。错的题往往是没用模板分层。"
8. **"看到大段材料就懵"** → "先看**最后一句问什么**。问'做法'就翻 G5；问'意义'就翻 G4 或 G6。读材料只圈 3 处：**主语/动词/总结句**。"
