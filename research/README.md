## 信息源（共同）

- 大连自 **2024 年起使用辽宁省统一命题**（与沈阳、抚顺等市同卷）
- 2026 中考时间：6 月 21–23 日
- 教材确认：化学 / 物理 / 数学 / 语文 = 人教统编版；**英语 = 外研版**（与多数省市不同）；道法 / 历史 = 部编版
- 核心来源：辽宁省样卷、2023–2025 真题（大连、辽宁省统一卷）、各区一模二模、教育局公文、知名教研网站
